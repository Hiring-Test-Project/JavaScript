# Settle a payment (JavaScript)

Implement `settle` in `src/sumAmounts.js`. Plan on 15 minutes. The rules are in [SPEC.md](SPEC.md).

Do not change `test/sumAmounts.test.js`.

## Run

From this directory:

```bash
npm test
```

## Submit

This directory is only the JavaScript task. Create a branch and push it. Do not change `test/`, `SPEC.md`, or `.github/`.

From this directory:

```bash
git checkout -b candidate/<your-name>
git add src/sumAmounts.js
git commit -m "Implement settlement"
git push -u origin candidate/<your-name>
```
